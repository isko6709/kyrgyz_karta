# 20 промптов для vibe-кодинга

Давай агенту по одному. После каждого: `npm run build` без ошибок, проверка в браузере, затем следующий. В начале сессии всегда: «Прочитай README.md и AGENTS.md».

1. **Каркас.** Прочитай README.md и AGENTS.md. Настрой проект: Tailwind, Zustand, MapLibre (react-map-gl/maplibre), Framer Motion, resolveJsonModule, скрипты sync:portraits/predev/prebuild. Убери демо-код Vite. Ничего лишнего не добавляй.

2. **Данные и типы.** Создай `src/lib/data.ts`: типизированный экспорт events, eras, layers (из events.json) и rulers (из rulers.json) по типам из `src/types.ts`. Добавь хелперы: `eventsForYear(year)`, `rulersForYear(year)`, `layersForYear(year)`, `eraForYear(year)`. Годы до н.э. отрицательные.

3. **Тема.** Задай светлую тему: CSS-переменные и Tailwind-токены из README (раздел 4), шрифты Lora + Inter с кириллицей. Сделай базовый лейаут: карта на весь экран, левая колонка (правители), правая колонка (события), таймлайн снизу.

4. **Состояние.** Создай `src/store.ts` (Zustand): `year`, `selectedEventId`, `playing`, `activeEraId`, `search`. Действия: setYear, selectEvent, togglePlay. При выборе события year ставится в его год.

5. **Карта.** Реализуй `MapView.tsx` на react-map-gl/maplibre. Старт: центр на Кыргызстане, zoom 5. Помни: в данных `[lat, lng]`, MapLibre ждёт `[lng, lat]`. Добавь элементы управления масштабом.

6. **Светлая подложка.** Подключи светлую подложку без современных подписей: Natural Earth суша/вода (GeoJSON в `public/data/base/`) либо стиль OpenFreeMap positron с отключёнными слоями подписей. Цвета: суша #EFE8D8, вода #DCE8EE, фон #F6F1E7. Переключатель «Современные границы» (по умолчанию выключен).

7. **Таймлайн.** Сделай `Timeline.tsx`: горизонтальный ползунок с кусочно-линейной шкалой из `src/lib/timeScale.ts`, перетаскивание мышью/пальцем, клавиши ← → (±1 год, Shift — ±25 лет), отображение текущего года (до н.э. корректно).

8. **Эпохи и метки.** На таймлайне нарисуй цветные сегменты эпох (`eras[].color`) с подписями, метки событий (точки) и полосы для событий с `yearEnd`. Клик по метке выбирает событие. Планируемые события (`planned`) рисуй пунктиром.

9. **Карточки событий.** Сделай `EventCard` и `EventList` (правая колонка): дата, заголовок, summary, цветная точка категории, бейдж достоверности (✅ high, ⚠️ medium, ❓ debated). Показывай события ближайшие к текущему году; выбранное раскрывается.

10. **Полёт к событию.** При выборе события: `flyTo` на `coords` с `zoom` (длительность 1400 мс), маркер с подсветкой, плавный возврат общего вида при снятии выбора.

11. **Слои территорий.** Для текущего года показывай слои `layersForYear(year)`: если есть `public/data/layers/<id>.geojson` — рисуй его, иначе прямоугольник из `bbox` с подписью «схематично». Заливка цветом эпохи с прозрачностью, тонкий контур, плавный fade 600 мс при смене года.

12. **Правители.** Сделай `RulerColumn.tsx` (левая колонка, как histography): правители с `from <= year <= to` (null пропускать), каждый через компонент `RulerAvatar`, под ним годы. Клик по правителю подсвечивает его слой. Не собирай пути к фото вручную.

13. **Название государства.** Над колонкой правителей показывай название государства/слоя текущего года (`layers[].title`) заглавными буквами. Если слоёв несколько — главный по приоритету, остальные мелким списком.

14. **Эпохи и поиск.** Добавь `EraChips` (клик — прыжок к началу эпохи) и `SearchBox` по `title`/`summary` событий и именам правителей; выбор результата ставит год и вызывает flyTo.

15. **Ссылки и Play.** Хэш-ссылки `#event=ID` и `#year=YYYY` (чтение при загрузке, обновление при смене). Кнопка Play: автоматически переходит по событиям по порядку, 5 секунд на событие, пауза по клику.

16. **Мобильная версия.** Адаптируй: на узком экране карточка события — bottom sheet (3 положения), правители — горизонтальная полоса над таймлайном, таймлайн с крупными зонами касания. Проверь 360–430 px.

17. **Достоверность и кредиты.** Добавь подпись «Границы схематичны. Даты до XIX века приблизительны», тултипы к бейджам `certainty`. В `RulerAvatar` показывай автора и лицензию из `public/portraits/credits.json`, если запись есть.

18. **Анимации и доступность.** Framer Motion для появления карточек и аватарок, `prefers-reduced-motion`, фокус и aria-label для таймлайна, меток и кнопок, контраст не ниже AA, управление с клавиатуры.

19. **GeoJSON-территории.** Реализуй загрузку и кэш `public/data/layers/*.geojson` с обработкой ошибок. Добавь страницу/режим `?debug=layers`, где видны все слои и отсутствующие файлы. Подготовь на каждый слой шаблон-файл в `docs/layers-todo.md`.

20. **Финал и деплой.** SEO-мета, favicon, OG-картинка, 404-безопасный `vercel.json`, `npm run build` без предупреждений, Lighthouse (производительность и доступность) > 90. Подготовь короткую инструкцию деплоя на Vercel в README.
