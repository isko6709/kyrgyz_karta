# Промпты V2: данные, границы, портреты

Давай по порядку: A → B → C. После каждого — `npm run build` и проверка в браузере.

## Промпт A — внедрить новые государства и правителей

```
Прочитай README.md и AGENTS.md. Я добавил файлы: src/data/layers.extra.json, src/data/rulers.extra.json, src/data/layer-sources.json.
1) Слей layers из layers.extra.json в layers в src/data/events.json, а rulers из rulers.extra.json в rulers в src/data/rulers.json. Дубликаты по id не создавай, существующие записи не меняй. Сохрани формат и порядок полей. После слияния extra-файлы оставь как есть.
2) Добавь новые id в docs/rulers_photo_checklist.csv (колонки как у существующих строк; image_type = imageType, file = public/portraits/<id>.webp).
3) Убедись, что левая колонка правителей, слои, поиск и таймлайн корректно работают с новыми записями, в том числе с layer: null и figureType: culture (деятелей культуры показывать отдельным бейджем, не как правителей).
4) Типы в src/types.ts обнови при необходимости.
Ничего не выдумывай и не меняй тексты. В конце: npm run build и краткий отчёт, сколько слоёв и правителей стало.
```

## Промпт B — реальные границы + полупрозрачные соседи на фоне

```
Прочитай README.md, AGENTS.md и src/data/layer-sources.json. Цель: настоящие (не прямоугольники) границы государств, а также полупрозрачные соседи на фоне.

1) Скрипт scripts/build-layers.mjs (Node 18+): делает shallow clone https://github.com/aourednik/historical-basemaps в .cache/ (добавь в .gitignore), читает список файлов geojson (индекс репозитория), для каждого слоя из layer-sources.json выбирает ближайший существующий снимок из years и фичи, у которых NAME или SUBJECTO (регистронезависимо) содержит одну из nameMatch. Геометрию объединяй, упрощай (turf simplify или mapshaper, tolerance ~0.02, цель ≤150 КБ на файл) и сохраняй в public/data/layers/<id>.geojson с properties {id,title,source,snapshotYear,schematic:false}. Слои с "modern": true (kirghiz_ao, kirghiz_ssr, kyrgyzstan) бери из полигона KGZ (Natural Earth или снимок 2010 из этого же датасета). Если фича не найдена — оставь существующий файл и запиши причину в docs/layers-report.md. Ничего не рисуй сам.

2) Контекст соседей: для текущего года выбирай ближайший снимок world_<год>.geojson целиком (все государства), упрощённый и сохранённый в public/data/context/. Рисуй его фоном: заливка по NAME стабильной пастельной палитрой, fill-opacity ~0.18, тонкий контур, подписи крупных государств (symbol layer, только при zoom < 6). Фокусное государство (слои текущего года) — fill-opacity ~0.45, контур толще, цвет эпохи, подпись заглавными. Переход между снимками — crossfade 500 мс (два источника, без мерцания). Клик/hover по соседу показывает его NAME во всплывающей подсказке.

3) UI: переключатель «Соседи» (по умолчанию включён) и легенда. Подпись: «Границы схематичны, источник: historical-basemaps (A. Ourednik и др.)». Открой LICENSE репозитория, проверь условия и добавь атрибуцию в README и интерфейс; если лицензия несовместима — остановись и сообщи.

4) Производительность: кэшируй загруженные GeoJSON, грузи лениво по году. В конце: npm run build, лог выбранных снимков по слоям и список слоёв без совпадений.
```

## Промпт C — автозаполнение аватарок точными фото

```
Прочитай README.md, AGENTS.md, public/portraits/README.md. Заполни портреты правителей автоматически и ТОЧНО.

Для каждого id из src/data/rulers.json, у которого imageType ≠ "none" и нет файла в public/portraits/:
1) Wikidata (wbsearchentities, языки ru и en) по name и commonsQuery. Выбери сущность только если это человек (P31 = Q5) и даты жизни/должность совпадают с display/from/to из rulers.json. При сомнении — пропусти.
2) Возьми изображение из P18. Нет P18 — используй pageimages (prop=pageimages&piprop=original) статьи Википедии (ru, en, ky) этого человека; нет и его — категорию Commons (P373) и самый подходящий портрет из неё.
3) Через Commons API (imageinfo + extmetadata) получи автора, лицензию и страницу файла. Разрешены только свободные лицензии (PD, CC0, CC BY, CC BY-SA). Fair use, NC, ND — отклонять.
4) Скачай (iiurlwidth=1000), вырежи квадрат 400×400 (sharp, лицо по центру), сохрани как public/portraits/<id>.webp. ОТКРОЙ изображение и проверь глазами: один человек, нужная эпоха, лицо различимо. Групповые фото кадрируй по нужному лицу или пропусти.
5) Запиши автора, лицензию, источник в public/portraits/credits.json и запусти npm run sync:portraits.
6) Если свободного фото нет (например, у части советских деятелей, как Абсамат Масалиев), НЕ бери фото из Google, новостей и соцсетей — это нарушение авторских прав. Оставь заглушку и запиши в docs/portraits-report.md: id, что пробовал, причину, ссылки на страницы, где можно запросить разрешение.
7) Для imageType = "none" (ранние каганы и т. п.) ничего не делай.
8) Соблюдай вежливость к API: User-Agent с контактом, не больше 1 запроса в секунду. Итог — таблица в docs/portraits-report.md: id → найдено / пропущено, лицензия, ссылка.
```
