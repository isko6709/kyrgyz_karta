# AGENTS.md — правила для ИИ-агентов (Cursor / Claude Code / др.)

Проект: интерактивная светлая карта истории Кыргызстана (от енисейских кыргызов до наших дней). Полное описание — в `README.md`. Читай оба файла перед работой.

## Стек и ограничения
- Vite + React 18 + TypeScript, Tailwind, Zustand, Framer Motion, **MapLibre GL** (`react-map-gl/maplibre`).
- Только фронтенд, **без бэкенда и БД**. Деплой — статикой на Vercel.
- Не использовать localStorage для данных приложения (допустимо только для настроек вроде языка).
- Тема **светлая** (палитра в README, раздел 4). Шрифты с кириллицей.

## Источники данных (единственный источник правды)
- `src/data/events.json` — события, эпохи (`eras`), слои территорий (`layers`).
- `src/data/rulers.json` — правители и фигуры (66 записей).
- `src/data/portraits.json` — **генерируется** скриптом, руками не править.
- Тексты, даты, имена **не хардкодить** в компонентах и **не выдумывать**. Если данных не хватает — оставить поле пустым и сообщить, а не придумывать.
- Типы — `src/types.ts`. Координаты в данных `[lat, lng]`; MapLibre требует `[lng, lat]`.

## Портреты (важно)
- Файлы: `public/portraits/<ruler.id>.(webp|jpg|jpeg|png|avif)`. Имя файла = `id` из `rulers.json`.
- Для показа аватарки **всегда** использовать `src/components/RulerAvatar.tsx` (внутри — `getPortrait(id)` из `src/lib/portrait.ts`). Не собирать пути к картинкам вручную и не хотлинкать внешние URL.
- Если файла нет, компонент показывает `_placeholder.svg` и подпись «условное изображение». Это штатное поведение, не ошибка.
- После того как пользователь добавил фото: запустить `npm run sync:portraits` (скрипт `scripts/sync-portraits.mjs`).
- **Не генерировать и не рисовать портреты** исторических лиц, у которых `imageType: "none"` (Барсбек, Ажо и др.): подлинных изображений не существует.
- Авторы и лицензии — в `public/portraits/credits.json` (`{ "<id>": { "author", "license", "source" } }`). Показывать в подписи/тултипе, если запись есть.

## Что должно получиться (MVP)
1. Карта на весь экран, светлая подложка без современных подписей.
2. Нижний таймлайн с неравномерной шкалой (`src/lib/timeScale.ts`), цветные сегменты эпох, метки событий, полосы для `yearEnd`.
3. Правая колонка: карточки событий выбранного года/эпохи (бейдж `certainty`, категория).
4. Левая колонка (как на histography): правители, у которых `from <= year <= to`, с `RulerAvatar` и названием государства (`layer` → `layers[].title`).
5. Слои территорий по текущему году: плавный fade; если нет `public/data/layers/<id>.geojson` — прямоугольник из `bbox` с пометкой «схематично».
6. Клик по событию → `flyTo`, подсветка слоя. Хэш-ссылки `#event=ID` и `#year=YYYY`. Кнопка Play.
7. Мобильная версия: карточка — bottom sheet.

## Порядок работы
Делай по одному шагу из `docs/PROMPTS.md`, после каждого — `npm run build` без ошибок. Не переписывай файлы целиком ради мелких правок. Не добавляй зависимости без необходимости.

## Тон и достоверность
- Спорные даты показывать с бейджем (`medium` ⚠️, `debated` ❓), не скрывать.
- В интерфейсе подпись: «Границы схематичны. Даты до XIX века приблизительны».
- Нейтральный тон в описаниях политических событий; ничего не добавлять от себя.
