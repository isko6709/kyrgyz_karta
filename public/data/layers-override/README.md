# Ручные оверрайды слоёв территорий (layers-override)

Файлы `<id>.geojson` из этой папки имеют **наивысший приоритет** при отображении границ исторического слоя:

1. **Приоритет в приложении**:
   Клиентский загрузчик сначала проверяет наличие файла в `public/data/layers-override/<id>.geojson`. Если файл найден, он загружается вместо базового слоя из `public/data/layers/<id>.geojson` и помечается в отладчике как `source: "override"`.

2. **Защита от перезаписи**:
   Скрипт `scripts/build-layers.mjs` проверяет эту папку и **никогда не перезаписывает** файлы из `public/data/layers-override/`. При пересборке границ они копируются в финальную сборку как приоритетные.

## Как создать или отредактировать слой через geojson.io:
1. Откройте в браузере [geojson.io](https://geojson.io/).
2. Перетащите в окно редактора существующий файл из `public/data/layers/<id>.geojson` (или нарисуйте полигон вручную).
3. Отредактируйте вершины и границы на интерактивной карте.
4. В меню **Save** выберите **GeoJSON**.
5. Сохраните скачанный файл с именем `<id>.geojson` (например, `kokand.geojson`) в эту папку: `public/data/layers-override/`.
6. Откройте карту в режиме `?debug=layers` — слой автоматически отобразится со статусом `override`.
